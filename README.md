# Omarchy customizations

User overlays for [Omarchy](https://omarchy.org/). Each theme lives in its own top-level directory.

| Directory | What it is |
|-----------|------------|
| [Matrix](Matrix/) | CRT phosphor theme, digital-rain screensaver, Brave chrome, Emacs theme |

```bash
git clone https://github.com/jandrusk/omarchy.git
cd omarchy/Matrix
./setup.sh
```
